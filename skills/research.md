# Research a Topic

Use this skill when asked to research, investigate, or gather information about a topic.

## Instructions

Follow this process in order:

1. **Check memory first**: `memory_search` for the topic — you may have notes already.
2. **Check documents**: `document_search` for relevant indexed content.
3. **Web search**: Use `web_search` with 2–3 different query angles:
   - Broad query: just the topic name
   - Specific query: topic + aspect you need
   - Recent query: topic + "2024" or "latest"
4. **Synthesize**: Combine all sources into a coherent answer.
5. **Save to memory**: Use `memory_write` to save key findings with a descriptive key.
6. **Index for later**: If you found substantial text, use `document_add` to index it.

## Output Format

```
**Research: [Topic]**

**Sources checked**: memory, documents, web

**Findings**:
[Your synthesized answer here]

**Saved to memory**: [key name]
```

## Tips
- Always check local sources before searching the web
- Prefer primary sources over summaries
- Note when information might be outdated
