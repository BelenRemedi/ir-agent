# Summarize Text

Use this skill when asked to summarize a document, article, or long text.

## Instructions

1. Read the full text first.
2. Identify the main topic or thesis.
3. Extract 3–5 key points supporting the main idea.
4. Note any important conclusions or takeaways.
5. Write a summary with:
   - **One sentence** overview (what + why it matters)
   - **Bullet points** for key points (max 5)
   - **One sentence** conclusion

## Format

```
**Summary**: [one sentence overview]

**Key Points**:
- [point 1]
- [point 2]
- [point 3]

**Conclusion**: [one sentence]
```

## Notes
- Keep summaries concise — aim for 20% of original length
- Preserve numbers, dates, and proper nouns accurately
- Do not add opinions or external information
